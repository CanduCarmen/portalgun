# Relay для Portal Gun

Мод клиентский, а обычный Minecraft-сервер не пересылает чужие пакеты, поэтому игроки видят порталы друг друга
через этот маленький сервер (нужен только Python 3, больше ничего).

    python3 portalgun_relay.py --port 8765 --token МОЙ_СЕКРЕТ

В игре у КАЖДОГО игрока: Shift+ПКМ с пушкой -> вкладка «Сеть» -> галочка, адрес `http://<ip>:8765`, тот же токен.
Порталы видны игрокам на одном сервере и в одном измерении. Порт 8765 должен быть доступен снаружи (VPS / проброс порта).
Хранится только в памяти и только пока игрок онлайн. Проверка: `curl http://<ip>:8765/health`.
